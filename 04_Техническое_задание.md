# Как устроена новелла?
* Она устроена в выборе действий которые можно выбрать с помощью комманд которые представленны выше ввода
* При неправильном выборе программа прерывает свою работу
# Сцены:
1. Сцены связаны при помоще выбора действий:
2. Для получение последующих действий нужно выбрать действие которое находиться на вашем этапе
# Выбор действий:
- 1. Оно меняется в зависимости от вашего предыдущего действия
- 2. Ситуация меняется когда выбираете определенный выбор.
# Какие варианты выбирает игрок?
1. Игрок выбирает варианты в программе именну ту которая нужно понять на сколько это хороший выбор для того чтобы найти выход со станции.
